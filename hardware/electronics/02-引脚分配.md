# 02 · 引脚分配（Mega 2560 PRO MINI）

> **这份表和 `firmware/include/HW_CONFIG.h` 必须保持同步。改一处就改两处。**

## 一、已分配引脚

| 功能 | **引脚** | 复用/说明 |
|---|---|---|
| **舵机 PWM** | **D5** | OC3A，独立定时器，不被其他 PWM 干扰 |
| **I²C · SDA** | **D20** | 硬件 I²C，⚠️ **经电平转换** |
| **I²C · SCL** | **D21** | 同上 |
| **上位机 UART · TX** | **D18** | **Serial1 TX**，⚠️ **分压到 3.3V** |
| **上位机 UART · RX** | **D19** | **Serial1 RX** |
| **JQ8900 · TX** | **D16** | **Serial2 TX**，⚠️ **必须分压** |
| **JQ8900 · RX** | **D17** | **Serial2 RX**（3.3V 直连可）|
| **JQ8900 · BUSY** | **D22** | 输入，播放状态（可省）|
| **电池电压** | **A0** | 分压后接入 |
| **急停按钮** | **D2** | INT4（也可轮询）|
| **蜂鸣器** | **D4** | 无喇叭时兜底 |
| **LED · 电源** | **D26** | |
| **LED · 运行** | **D27** | |
| **LED · 故障** | **D28** | |
| **LED · 通信** | **D29** | |
| **调试串口** | **D0 / D1** | **Serial0** —— 留给 USB 调试 ★ |
| **舵机电流采样**（可选）| **A1** | 采样电阻 + 运放 |

### ★ 两条设计要点

1. **上位机走 `Serial1`（D18/D19）** —— 把 `Serial0`（D0/D1）留给 USB。
   这样**插着 USB 也能收上位机指令**，调试期极方便。
2. **不要占用 D2/D3/D20/D21 做普通 IO** —— 它们是外部中断脚。
   当前设计里编码器走 I²C 了，**6 个中断脚全部空闲**，留给未来。

## 二、空闲引脚（全部引到排针）

| 范围 | 数量 | 用途 |
|---|---|---|
| D6~D13 | 8 | 备用（PWM 可用）|
| D23~D25, D30~D53 | 27 | 备用 |
| A2~A15 | 14 | 备用 ADC |
| D14/D15 | 2 | **Serial3** 备用 |
| 3.3V / 5V / GND | — | **每个排针组旁都要有** |

> **建议**：把空闲引脚按「D 组 / A 组」两排排针引出，**每 4 个信号脚配 1 个 GND**。

## 三、电平转换设计

```
              ┌──────────────┐
  D20 (5V) ───┤ PCA9306 或   ├─── I²C 总线 3.3V ─── AS5600 / MPU6050 / 电机模块
  D21 (5V) ───┤ TXS0102      │
              └──────────────┘

              ┌──────────────┐
  D18 (5V) ───┤ 1kΩ ─┬─ 2kΩ ├── GND     ← 分压到 3.3V，送 RDK X3
              └──────┘   │
                        └──→ RDK X3 RX

  D16 (5V) ───┤ 1kΩ ─┬─ 2kΩ ├── GND     ← 分压到 3.3V，送 JQ8900 RX
              └──────┘   │
                        └──→ JQ8900 RX
```

**★ I²C 上拉电阻的位置**：**拉在 3.3V 侧**（因为总线上全是 3.3V 器件）。
若电平转换芯片自带，则不要再外加，否则上拉过重。
