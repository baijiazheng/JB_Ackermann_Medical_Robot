# 01 · 设计输入

> **这份文档是画板的唯一依据。** 任何 PCB 上的接口/空间/走线，都必须能追溯到这里的某一条功能。

---

## 一、系统架构（三层分离）

```
┌─────────────────────────────────────────────────────────┐
│ 上位机  RDK X3 4GB（ROS2）                              │
│   · 视觉：二维码/标签识别（200万像素 30帧 摄像头）        │
│   · 语义："理解信息指向" → 输出目标窗位 + 目标样本        │
│   · 规划：进框路径 · 语音内容决策                         │
│   · 雷达：YDLIDAR T-mini Plus（直插上位机）              │
└──────────────────┬──────────────────────────────────────┘
                   │ UART（3.3V ↔ 5V 需电平处理）
┌──────────────────▼──────────────────────────────────────┐
│ 下位机  Mega 2560 PRO MINI（本板插上去）                 │
│   · 接收：目标转角 δ + 目标速度 v                        │
│   · 执行：舵机 PWM + I²C 电机指令                        │
│   · 反馈：AS5600 实测转角 · 编码器里程 · MPU6050 姿态     │
│   · 播报：JQ8900 串口语音                                │
│   · 保护：看门狗 · 失联停车 · 电池低压告警                │
└──────────────────┬──────────────────────────────────────┘
                   │ I²C（3.3V）+ PWM + UART
┌──────────────────▼──────────────────────────────────────┐
│ 外设层                                                   │
│   hiwonder 四路编码电机模块 · 舵机 · AS5600 · MPU6050     │
│   JQ8900-16P + 4Ω3W 喇叭 · 电源                              │
└─────────────────────────────────────────────────────────┘
```

**判据**：**凡是与 Arduino 引脚号绑定的东西，都要能被一块转接板隔离** —— 以后换 STM32 只换那块。

## 三、接口总表（PCB 布局的依据）

| # | 器件 | 接口 | 电平 | 峰值电流 | 端子规格 |
|---|---|---|---|---|---|
| 1 | **hiwonder 电机模块** | **I²C** | 3.3V ⚠️ | 逻辑 <50mA（功率另供）| **4P XH2.54** |
| 2 | **舵机** | PWM | 5V 信号 | **2.3A @7.4V** | **3P XH2.54** + 粗线 |
| 3 | **AS5600** | I²C | 3.3V | 10mA | 4P XH1.25 |
| 4 | **MPU6050** | I²C | 3.3V（模块可 5V 供电）| 10mA | 4P XH1.25 |
| 5 | **上位机 RDK X3** | UART | **3.3V** ⚠️ | — | 4P XH2.54 |
| 6 | **JQ8900-16P** | UART | **3.3V TTL** ⚠️ | ~200mA | **2×8P 排母** |
| 7 | **喇叭** | 模拟 | — | — | **2P 端子** |
| 8 | **电池** | 电源 | 11.1V | **7.7A** | **XT30 / KF128** |
| 9 | **5V 输出**（给上位机/雷达等）| 电源 | 5V | 4.8A | 2P + 分支 |

### ⚠️ 电平陷阱（必须处理）

| 信号 | 方向 | 问题 | 方案 |
|---|---|---|---|
| Arduino TX1 (5V) → RDK X3 RX (3.3V) | 出 | **会烧 RDK** | 电阻分压 或 电平转换 |
| RDK X3 TX (3.3V) → Arduino RX1 | 入 | 5V 阈值勉强 | 建议加缓冲，或直连实测 |
| Arduino TX2 (5V) → **JQ8900 RX (3.3V)** | 出 | **会烧模块** | **必须分压** |
| JQ8900 TX (3.3V) → Arduino RX2 | 入 | 可直连 | — |
| **I²C 总线（3.3V 器件）** | 双向 | 5V 会烧 | **双向电平转换（TXS0102 / PCA9306）** |

> **★ 最优解**：Mega PRO MINI 有 **3.3V 输出**。若把 I²C 上拉拉到 3.3V，且主控 I²C 引脚通过电平转换，即可安全共存。
> **更省事的方案**：所有 3.3V 器件挂一条独立 I²C，用**双向电平转换芯片**统一转换（推荐 PCA9306，便宜且双向）。

## 四、引脚预算

| 资源 | 需要 | Mega 2560 PRO MINI | 余量 |
|---|---|---|---|
| **I²C** | 1 条（挂 3 个器件）| D20/D21 | ✅ |
| **UART** | **2**（上位机 + JQ8900）| **4** | ✅ 余 2 |
| **PWM** | 1（舵机）| 15 | ✅ |
| **ADC** | 1（电池）| 16 | ✅ |
| **数字 IO** | LED×4 + 蜂鸣器 + 急停 + BUSY ≈ 7 | 54 | ✅ |
| **外部中断** | 0（编码器走 I²C 了）| 6 | ✅ 全空 |

**→ 极其宽裕。剩余引脚全部引出到排针，方便以后扩展。**

## 五、验收方法（画完板子怎么验）

| 阶段 | 验收动作 | 通过标准 |
|---|---|---|
| 原理图 | ERC | 无 error |
| PCB | DRC | 无 error；功率区线宽 ≥1.5mm |
| 打样回来 | **上电前**：万用表测 5V/3.3V 对地电阻 | 无短路 |
| 上电 | 空载测三路电压 | 5V ±5%，3.3V ±3% |
| 通信 | I²C 扫描 `i2cdetect` 等价物 | 三个器件地址都能看到 |
| 舵机 | 给 1500µs 脉冲 | 中位，且 **不出 1098~1709 范围** |
| 音频 | 串口发播放指令 | 喇叭出声，且**不干扰 I²C** |
| 满载 | 舵机堵转 + 上位机跑起来 | 5V 不塌陷，复位不重启 |

## 六、PCB 尺寸决策（2026-10-05 定）

### 主控板精确尺寸（RobotDyn 官方机械图）

```
Mega 2560 PRO MINI
  本体     38.00 × 52.00 mm
  排针行距 32.01 mm
  安装孔   2 × φ3.2 mm
  复位按钮区 14.48 × 12.50 mm
→ 含排母与留白，实际占位约 45 × 58 mm
```

### ★ 选定尺寸：**100 × 80 mm**

| 项 | 值 |
|---|---|
| **PCB** | **100 × 80 mm** |
| 板厚 | 1.6 mm（**建议 2.0**，反复插拔端子更牢）|
| 圆角 | R2（沿用轮腿项目习惯）|
| 安装孔 | **4 × φ3.2（M3），距板边 5mm** |

### 为什么是 100×80

| # | 理由 |
|---|---|
| 1 | **卡在立创 10×10cm 最便宜打样档** —— 成本最优 |
| 2 | 13 个端子沿三边排得下，**丝印看得清** |
| 3 | 电源区（3 Buck + 2 大电容 + 3 保险丝）**有散热间距** |
| 4 | 主控 45×58 放得下，四周**留调试空间** |
| 5 | **宽 80 < 145**，稳稳装进 161 车宽的底板 |

### 机械空间校核

```
车架底板：285 mm(长) × 161 mm(宽)

沿车长分配：
  RDK X3  145  +  主控板 100  +  接线余量 40  =  285  ✓

⚠️ RDK X3 宽 90 + 主控板宽 80 = 170 > 161
   → 必须【前后串排】，不能并排
```
