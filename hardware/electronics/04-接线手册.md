## 二、JQ8900-16P 引脚（★ 按你发的实际模块）

**2×8 = 16 脚，从左到右、从上到下：**

```
 左侧（1~8）              右侧（16~9）
 ─────────────           ─────────────
 1  VPP   一线串口控制      16 DAC    模拟音频输出
 2  BUSY  播放指示(高=在播)  15 IO1
 3  RX    UART 输入 ⚠️3.3V  14 IO2
 4  TX    UART 输出 3.3V    13 IO3
 5  GND   电源地            12 IO4
 6  DC-5V 电源 ⚠️≤5.2V      11 IO5
 7  SPK-  喇叭 -            10 IO6
 8  SPK+  喇叭 +             9 IO7
```

### 接法

| 模块脚 | 接到 | 说明 |
|---|---|---|
| **1 VPP** | **不接** | 用 UART 控制，不用一线串口 |
| **2 BUSY** | **D22** | 可选，读播放状态 |
| **3 RX** | **D16 (TX2)** | ⚠️ **必须分压**（1kΩ + 2kΩ）|
| **4 TX** | **D17 (RX2)** | 3.3V，可直连 |
| **5 GND** | GND | |
| **6 DC-5V** | **5V** | ⚠️ **绝不可接 7.4V / 11.1V** |
| **7 SPK-** | 喇叭 − | |
| **8 SPK+** | 喇叭 + | **4Ω 3W** |
| 9~15 IO1~IO7 | **悬空**（可引到排针备用）| |
| **16 DAC** | 不接 | |

### ⚠️ 三个坑

1. **RX 是 3.3V TTL** —— Arduino 的 5V TX **直接接会烧模块**，必须分压
2. **DC-5V 不可超 5.2V** —— 只能从 5V 支路供，**不能接 7.4V**
3. **喇叭线远离 I²C** —— 功放瞬态电流会串扰，走线分开 + 喇叭线双绞

### 喇叭规格

**4Ω 3W**（你已有可用的）✓
- 若换 8Ω：音量会小一半，模块仍能推
- 若换 4Ω 5W：模块推不动，会失真

### hiwonder 电机模块寄存器表（已确认）

| 寄存器 | 用途 | 读写 |
|---|---|---|
| `0x14` | 电机类型（写 `3` = JGB37-520 12V 110RPM 90:1）| W |
| `0x15` | 编码器方向极性 | W |
| **`0x33`** | **四路闭环固定速度**（4× int8_t，范围约 **−50 ~ +50**）| W |
| **`0x3C`** | **四路编码器累计脉冲**（**16 字节** = 4× int32_t，小端）| R |

**电机方向极性**（前代实测）：`M1=+1, M2=−1, M3=−1, M4=+1`

**★ 上电初始化代码**（直接抄）：
```cpp
Wire.begin();
Wire.beginTransmission(0x34);
Wire.write(0x14); Wire.write(3);      // 电机类型 = JGB37-520 12V
Wire.endTransmission();
Wire.beginTransmission(0x34);
Wire.write(0x15); Wire.write(0);      // 编码器极性 = 默认
Wire.endTransmission();
```


## 四、接线顺序（上电前检查表）

```
□ 1. 万用表测 5V / 7.4V / 3.3V / 11.1V 对地电阻，无短路
□ 2. 电池先不接，用稳压电源限流 0.5A 试上电
□ 3. 测三路电压正常 → 断开
□ 4. 插主控，再限流上电 → 测主控能跑（LED 闪）
□ 5. 接 I²C 三件 → 扫描地址，三个都能看到
□ 6. 接舵机 → 发中位脉冲 1500µs
□ 7. 接 JQ8900 + 喇叭 → 发播放指令
□ 8. 接上位机 → 串口互发测试
□ 9. 全部接上，满载跑 5 分钟 → 测温升、电压跌落
```

## 五、注意事项

| # | 事项 |
|---|---|
| 1 | **每次改接线先断电** —— 带电插拔 I²C 极易烧器件 |
| 2 | **舵机不要用手硬掰** —— 会打坏齿轮 |
| 3 | **首版打样建议做 2 块** —— 留一块备用/对照 |
| 4 | **丝印必须标**：端子名 + 电压 + 引脚名（调试时救命）|
| 5 | **板边留 4× M3 安装孔** + 与底板固定的定位 |
