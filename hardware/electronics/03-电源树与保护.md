## 二、电源树

```
        3S 锂电 11.1V
             │
      ┌──────┴──────┐
      │ 主开关      │
      │ + Mini Blade 汽车保险丝 10A          ← V2.0 清单 ★★★★★
      └──────┬──────┘
             │ 11.1V 总线（总电流 ≈ 7.7A）
    ┌────────┼──────────────────┬───────────────────┐
    │        │                  │                   │
 [电机直供]  [Buck → 7.4V]   [Buck → 5V / 8A]   [Buck → 3.3V]
  11.1V       ≥5A               │                   │
    │        │                  ├─ RDK X3 (3A)       ├─ MPU6050
 hiwonder    舵机 TBSN-K15      ├─ 雷达 (0.3A)       ├─ AS5600
 电机模块     │                 ├─ 摄像头 (0.5A)     └─ 电机模块逻辑
 （功率由                        ├─ JQ8900 (0.2A)
   模块自供）                    └─ 主控 5V 脚 ★不经过 VIN
```

### ⚠️ 三条硬规矩

| # | 规矩 | 为什么 |
|---|---|---|
| **1** | **主控的 5V 脚由外部 Buck 直接喂，绝不走 VIN** | 板载是线性稳压器，`(11.1−5)×4.8A = 29W` 会烧 |
| **2** | **同时插 USB 调试时**，5V 支路要能断开或加理想二极管 | 防止倒灌 |
| **3** | **3.3V 不要从 5V 用 LDO 降**（如果 5V 已是大电流 Buck）| 用独立小 LDO 或从 11.1V 降，避免 5V 支路噪声进 3.3V |

## 三、保护设计（含 V2.0 清单落地）

| 你的 V2.0 清单 | V1.2 怎么落地 |
|---|---|
| **AMS1117 → Buck DC-DC** ★★★★★ | 5V 用 **MP1584 / XL4015 / SY8205 级 Buck ≥8A**；3.3V 用 AP2112 或 MP2359 |
| **0805 PPTC → Mini Blade 汽车保险丝** ★★★★★ | 主回路 **10A Mini Blade**；舵机支路 **5A**；5V 支路 **8A** |
| **所有重要信号加 Test Point** ★★★★★ | 5V / 7.4V / 3.3V / 11.1V / GND / SDA / SCL / TX1 / RX1 / TX2 / RX2 / 舵机 PWM 各留一个焊盘 |
| **TB6612 VM 旁加 ≥1000µF 低 ESR 电解** ★★★★☆ | **V1.2 没有 TB6612**（走 I²C 模块）→ 改为 **11.1V 总线入口 + 5V Buck 输入各并 ≥470µF 低 ESR + 0.1µF** |
| **动力区/控制区分离** ★★★★☆ | PCB 分四区（见 `01`），**功率地与信号地单点汇接** |
| TB6612 保持 | **不适用** —— 改用 hiwonder I²C 模块 |

### 额外建议（V1.1 没提但重要）

| # | 保护 | 说明 |
|---|---|---|
| 1 | **电池反接保护** | P-MOS 防反接，或至少一个防反二极管 |
| 2 | **电池低压告警** | ADC 监测，低于 3.3V/cell（9.9V）时蜂鸣 + LED，**并在 3.0V/cell 前强制停** |
| 3 | **舵机独立保险** | 舵机堵转是大电流源，单独 5A 保险 |
| 4 | **上电浪涌抑制** | 大电容前加 NTC 或软启动 |
| 5 | **看门狗** | 下位机失联上位机 → 自动停车（软件层，但要有硬件急停兜底）|

## 六、★ 电源树定案（2026-10-05，白佳正拍板）

### 架构：三路独立

```
3S 锂电 11.1V  →  总开关 + 总保险丝(Mini Blade 10A)  ──2.0mm²──┐
                                                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
  ① 电机直供 11.1V        ② DC-DC 5V ≥6A         ③ DC-DC 7.4V ≥5A
        │                       │                       │
  hiwonder 模块          ┌──────┴──────┐                │
  四路编码电机            │             │                │
                    RDK X3 3A     主板 5V 1.2A      主板 7.4V 2.3A
                                                        │
                                                   舵机 3P 端子
                                                   (板上直转，不再变换)
```

**见** `docs/电源树.png`

### ★ 为什么 7.4V 要单独一路（三个不能这么做）

| ✗ 做法 | 为什么不行 |
|---|---|
| 从 5V 升压到 7.4V | 5V 那路已 4.15A/5A，再抽 3.9A 去升压**直接崩** |
| 从 3S 平衡头取 2S（≈7.4V）| 只有一路放电 → **电池组失衡**，充电器报错，长期毁电池 |
| 11.1V 直供舵机 | TBSN-K15 是 **2S(7.4V) 规格**，11.1V 会烧 |

**→ 必须从 11.1V 独立降一路。放在【板外模块】实现（散热甩给模块厂，和 5V 一致）。**

### 线径与端子匹配（★ 重要：2mm² 接不进 XH2.54）

| 位置 | 电流 | 线径 | 端子 |
|---|---|---|---|
| 电池→总开关/保险丝 | **7.7A** | **2.0 mm²** | **XT30 / KF128-5.08** |
| 总开关→电机模块 | 3.0A | 1.0~1.5 mm² | KF128 / XT30 |
| 总开关→5V 模块 | 3.5A | 1.5 mm² | KF128 / XT30 |
| 总开关→7.4V 模块 | 1.8A | 1.0 mm² | KF128 / XT30 |
| 模块→RDK X3（5V）| 3.0A | **0.5 mm² 上限** | XH2.54 |
| 模块→主板（5V）| 1.2A | 0.5 mm² | XH2.54 |
| 模块→主板（7.4V）| 2.3A | **0.5 mm² 上限** | XH2.54 |
| 主板→舵机 | 2.3A | 0.5 mm² | XH2.54 3P |
| 传感器 | <0.5A | 0.3 mm² | XH1.25 |

> **2mm² 铜线直径 ≈1.6mm，而 XH2.54 压接范围是 AWG22~28（0.3~0.5mm²）**
> → **主干和分支必须用不同线径与端子。**

### 5V 余量校核

| 负载 | 电流 |
|---|---|
| RDK X3 | 3.00 A |
| 摄像头 | 0.50 A |
| 雷达 | 0.30 A |
| JQ8900 + 功放 | 0.20 A |
| 主控 + 传感器 | 0.15 A |
| **合计** | **4.15 A** |

**→ 单块 5A 模块占 83%，余量仅 17% ⚠️**
**→ 选 ≥6A 模块，或分两块（RDK 一块 / 主板一块，顺带隔离噪声）**
