## 二、电源树

```
        3S 锂电 11.1V
             │
      ┌──────┴──────┐
      │ 主开关      │
      │ + Mini Blade 汽车保险丝 10A          ← V2.0 清单 ★★★★★
      └──────┬──────┘
             │ 11.1V 总线（总电流 ≈ 7.7A）
    ┌────────┼──────────────────┬───────────────────┐
    │        │                  │                   │
 [电机直供]  [Buck → 7.4V]   [Buck → 5V / 8A]   [Buck → 3.3V]
  11.1V       ≥5A               │                   │
    │        │                  ├─ RDK X3 (3A)       ├─ MPU6050
 hiwonder    舵机 TBSN-K15      ├─ 雷达 (0.3A)       ├─ AS5600
 电机模块     │                 ├─ 摄像头 (0.5A)     └─ 电机模块逻辑
 （功率由                        ├─ JQ8900 (0.2A)
   模块自供）                    └─ 主控 5V 脚 ★不经过 VIN
```

### ⚠️ 三条硬规矩

| # | 规矩 | 为什么 |
|---|---|---|
| **1** | **主控的 5V 脚由外部 Buck 直接喂，绝不走 VIN** | 板载是线性稳压器，`(11.1−5)×4.8A = 29W` 会烧 |
| **2** | **同时插 USB 调试时**，5V 支路要能断开或加理想二极管 | 防止倒灌 |
| **3** | **3.3V 不要从 5V 用 LDO 降**（如果 5V 已是大电流 Buck）| 用独立小 LDO 或从 11.1V 降，避免 5V 支路噪声进 3.3V |

## 三、保护设计（含 V2.0 清单落地）

| 你的 V2.0 清单 | V1.2 怎么落地 |
|---|---|
| **AMS1117 → Buck DC-DC** ★★★★★ | 5V 用 **MP1584 / XL4015 / SY8205 级 Buck ≥8A**；3.3V 用 AP2112 或 MP2359 |
| **0805 PPTC → Mini Blade 汽车保险丝** ★★★★★ | 主回路 **10A Mini Blade**；舵机支路 **5A**；5V 支路 **8A** |
| **所有重要信号加 Test Point** ★★★★★ | 5V / 7.4V / 3.3V / 11.1V / GND / SDA / SCL / TX1 / RX1 / TX2 / RX2 / 舵机 PWM 各留一个焊盘 |
| **TB6612 VM 旁加 ≥1000µF 低 ESR 电解** ★★★★☆ | **V1.2 没有 TB6612**（走 I²C 模块）→ 改为 **11.1V 总线入口 + 5V Buck 输入各并 ≥470µF 低 ESR + 0.1µF** |
| **动力区/控制区分离** ★★★★☆ | PCB 分四区（见 `01`），**功率地与信号地单点汇接** |
| TB6612 保持 | **不适用** —— 改用 hiwonder I²C 模块 |

### 额外建议（V1.1 没提但重要）

| # | 保护 | 说明 |
|---|---|---|
| 1 | **电池反接保护** | P-MOS 防反接，或至少一个防反二极管 |
| 2 | **电池低压告警** | ADC 监测，低于 3.3V/cell（9.9V）时蜂鸣 + LED，**并在 3.0V/cell 前强制停** |
| 3 | **舵机独立保险** | 舵机堵转是大电流源，单独 5A 保险 |
| 4 | **上电浪涌抑制** | 大电容前加 NTC 或软启动 |
| 5 | **看门狗** | 下位机失联上位机 → 自动停车（软件层，但要有硬件急停兜底）|

## 五、验收方法

| 步骤 | 通过标准 |
|---|---|
| 上电前万用表测各电源对地电阻 | 无短路 |
| 空载上电 | 11.1V / 7.4V / 5V ±5% ／ 3.3V ±3% |
| 舵机堵转 2 秒 | 5V 跌落 <5%，主控不复位 |
| 上位机满载 | 同上 |
| 喇叭播报 | 5V 纹波 <100mV，I²C 不丢包 |
