# jb_apriltag_align · 最小视觉闭环

> **摄像头 → AprilTag 检测 → P 控制 → 串口 → 下位机 → 车动 → 回到摄像头**

## 闭环结构

```
                    ┌──────────────────────────────────────┐
                    │                                      │
   ┌────────┐   ┌───▼────┐   ┌────────┐   ┌────────┐   ┌──▼───┐
   │ 摄像头  │──→│ AprilTag│──→│ P 控制器│──→│ 串口    │──→│ 下位机 │
   │/video8 │   │  检测   │   │ (v, ω) │   │ttyS0   │   │Mega  │
   └────────┘   └────────┘   └────────┘   └────────┘   └──┬───┘
        ↑                                                  │
        └──────────────── 车动了，图像变了 ─────────────────┘
```

## ★ 为什么用视觉伺服而不是 SLAM（做最小闭环）

| | **AprilTag 视觉伺服** | **SLAM（gmapping）** |
|---|---|---|
| 输出 | **相对目标的横向/纵向误差** | 全局位姿 + 地图 |
| 适合 | **对准、进框** | 从 A 开到 B |
| 需要 | **只有摄像头（已有）** | **里程计 odom + 雷达 + 建图时间** |
| 现在能跑吗 | ✅ **今天就能** | ❌ **AS5600 没到，odom 做不了** |

**→ 结论：最小闭环 = AprilTag 视觉伺服。SLAM 是后续加分项。**

## 控制律（P 控制器）

```
横向误差 ex_norm = (标签中心x - 图像中心x) / 图像中心x     归一化到 [-1,1]

纵向距离 dist = (标签真实边长 × 焦距) / 标签像素边长         针孔模型单目测距
纵向误差 ez   = dist - target_dist

线速度  v = Kp_dist × ez      限幅 [v_min, v_max]，dist<stop_dist 时 v=0
角速度  ω = -Kp_yaw × ex_norm 限幅 ±w_max（负号：标签偏右→右转→ω为负）
```

**★ 为什么用 P 不用 PID**：视觉伺服的误差本身快速变化，积分项易累积过冲，
微分项对图像噪声敏感。**P 够用，调参简单（只有 2 个参数）。**

**★ 阿克曼特性**：`ω` 只在有速度时有效。`v=0` 而 `ω≠0` 时，下位机做"原地打方向"
（舵机转到位但车不动）—— 对准时这反而好（先打死方向再走）。

## 串口协议

```
发送:  "V,<linearX>,<angularZ>\n"
  linearX  : m/s     前进速度（负=后退）
  angularZ : rad/s   角速度（正=左转）
```

**与下位机 `UartProtocol.cpp` 的解析完全对应。**

## 跑法

```bash
# 一键：摄像头 + 对准节点
ros2 launch jb_apriltag_align align.launch.py

# 直接跑
ros2 run jb_apriltag_align align_node \
  --ros-args -p port:=/dev/ttyS0 -p tag_id:=0 -p target_dist:=0.5 \
             -p kp_dist:=1.2 -p kp_yaw:=2.0
```

## 调参指南

| 现象 | 调什么 |
|---|---|
| **冲过头** | 降 `kp_dist` 或降 `v_max` |
| **走太慢/走不动** | 升 `v_min`（电机死区）|
| **左右摆（震荡）** | 降 `kp_yaw` |
| **对不准 / 反应迟钝** | 升 `kp_yaw` |
| **停得太远/太近** | 调 `stop_dist` / `target_dist` |

## ⚠️ 必须先做的事

### 1. 标定相机内参（否则测距不准）

**代码里的 `fx=fy=700, cx=640, cy=360` 是【估计值】，正式用必须标定。**

```bash
# 用棋盘格标定，得到 camera_matrix 和 dist_coeffs
# 参考 JB_AprilTag_Tracker/upper_computer/src/ysbl_vision/ 里的标定脚本
# 标定后改 align_node.py 里的 fx/fy/cx/cy
```

### 2. 打印 AprilTag（tag36h11，ID=0，边长 50mm）

**⚠️ 打印时不要缩放！** 缩放了实际边长就变了，测距会偏。
打印后**用尺子量一下实际边长**，改 `tag_size` 参数。

### 3. 确认下位机波特率和串口

**RDK X3 的串口**：
- `/dev/ttyS0`（40PIN 上的 UART，要 `sudo` 或加入 `dialout` 组）
- 或 USB-TTL 转接：`/dev/ttyUSB0`
