### 阿克曼运动学（核心）

```python
# 输入：线速度 v、角速度 ω
# 输出：前轮转角 δ、后轮线速度 v
R = v / ω                          # 转弯半径
delta = atan(L / R)                # L = 轴距 = 200mm
# 约束：
#   |delta| <= delta_max (35°)
#   若 |delta| 超限 → 限速，不做原地转
```

### ★ 复用关键：接口一模一样

**前代（差速）：**
```cpp
class DifferentialDrive {
    void setVelocity(float linearX, float angularZ);   // m/s, rad/s
};
```

**本代（阿克曼）—— 接口刻意保持一致：**
```cpp
class AckermannDrive {
public:
    AckermannDrive(MotorDriverI2C& motor, Servo& servo);
    void begin();
    void setVelocity(float linearX, float angularZ);   // ← 同样的签名
    void stop();
private:
    MotorDriverI2C& motor;
    Servo& servo;
    float wheelbase = 200.0f;       // 轴距 L (mm)
    void computeSteering(float linearX, float angularZ,
                         float& deltaDeg, float& speed);
};
```

**→ 上位机的 UART 协议、指令格式、ROS2 节点全都不用改，只换下位机执行层。**

### 阿克曼执行层（与差速的唯一区别）

```cpp
// 输入：linearX (m/s), linearZ (rad/s)
if (fabs(angularZ) < 1e-3) {
    deltaDeg = 0;                       // 直行，前轮回正
} else {
    float R = linearX / angularZ;       // 转弯半径 (mm)
    deltaDeg = atan(L / R) * 180/PI;    // 阿克曼：tan(δ) = L / R
    if (fabs(deltaDeg) > DELTA_MAX) {   // DELTA_MAX = 35°
        // 超出舵机行程 → 限速，不原地转
        linearX *= DELTA_MAX / fabs(deltaDeg);
        deltaDeg = (deltaDeg > 0) ? DELTA_MAX : -DELTA_MAX;
    }
}
// 舵机脉宽（线性插值；标定点 0°=1500µs, +35°=1098µs）
int pulse = 1500 - (int)(deltaDeg * 11.7f);
servo.writeMicroseconds(pulse);
motor.setChassisSpeed(speed, speed);
```

**⚠️ 阿克曼的物理限制**：**不能原地转向**（`linearX = 0` 时 `R = 0`，`δ → 90°`）。
**上位机规划时必须保证 `|linearX| > 0`**，否则下位机应拒绝或强制最小速度。
