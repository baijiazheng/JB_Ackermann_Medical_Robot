# 04 · 软件架构

## 上位机（ROS2）

```
ros2_ws/src/
├── jb_vision/          视觉：二维码/标签识别 → 语义
│   ├── 节点：camera_node（取流）
│   ├── 节点：detector_node（检测）
│   └── 节点：interpreter_node（语义 → 目标窗口/样本）
├── jb_decision/        决策：进框路径 + 语音内容生成
│   └── 节点：mission_node（状态机）
├── jb_control/         控制：轨迹 → (δ, v)
│   └── 节点：ackermann_node（阿克曼运动学）
├── jb_serial/          通信：与下位机的 UART 协议
│   └── 节点：serial_bridge
└── jb_bringup/         总启动
```

### 阿克曼运动学（核心）

```python
# 输入：线速度 v、角速度 ω
# 输出：前轮转角 δ、后轮线速度 v
R = v / ω                          # 转弯半径
delta = atan(L / R)                # L = 轴距 = 200mm
# 约束：
#   |delta| <= delta_max (35°)
#   若 |delta| 超限 → 限速，不做原地转
```

## 下位机（Arduino / 未来 STM32）

```
firmware/
├── include/HW_CONFIG.h      引脚定义（唯一来源）
└── src/
    ├── main.cpp             主循环（定时器调度）
    ├── cmd_parser.cpp       UART 协议解析
    ├── servo_ctrl.cpp       舵机 PWM（脉宽表标定）
    ├── motor_i2c.cpp        hiwonder 模块 I²C 驱动
    ├── feedback.cpp         AS5600 / MPU6050 / 电压
    └── audio.cpp            JQ8900 播放控制
```
