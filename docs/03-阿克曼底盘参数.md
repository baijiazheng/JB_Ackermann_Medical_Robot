### 阿克曼原理（正确公式）

```
cot(δo) − cot(δi) = K / L     其中 K = 轮距（不是 W！）

★ 经典公式 cot(δo)−cot(δi) = W/L 只在【主销偏移距 s = 0】时成立。
  本车主销在轮内侧 s=38mm，必须用 K = (W + 2s) 修正。
  若误用经典公式，35° 时误差可达 2.47°。
```

## 六、材料与工艺

| 件 | 材料 | 要求 |
|---|---|---|
| 转向节 / 前桥 | **PETG**（或玻纤，⚠️ 见下）| 填充 ≥50%，壁 ≥1.6mm，层高 0.2 |
| 底板 / 车架 | **玻纤板** | CNC/激光切；**切割粉尘有毒，戴 N95** |
| 舵机座 | **CNC 钣金** | 折弯件 |
| 车架 | 待定 | |

> ⚠️ **玻纤做羊角有风险**：FR4 是层压板，**层间强度远低于平面内**，受弯矩+冲击容易劈裂。
> 若坚持用，须**多层叠压 + 纤维方向交错 + 厚度 ≥5mm**。

**打印朝向**：转向节**竖着打**（套筒轴 = 打印 Z），让轮轴座的弯曲应力落在平面内。
