# 01 · 比赛任务与规则

## 赛事

**华北五省（市、自治区）大学生机器人大赛 · 智慧医疗服务机器人（专项赛道）**
校赛答辩：**2026-09-23** ✅ 已通过

## 任务链（从感知到动作）

```
① 看到信息        二维码 / 标签 / 文字牌
        ↓
② 理解信息指向     判断"去哪个窗口、取什么样本"
        ↓
③ 语音播报        把理解结果说出来
        ↓
④ 精准进框        开到指定区域并停稳
```

## 硬性规则（★ 必须遵守）

| 项 | 要求 | 我们的取值 | 状态 |
|---|---|---|---|
| **底盘结构** | **阿克曼结构** | 阿克曼（主销 W=161, s=38）| ✅ |
| **投影尺寸** | **≥ 270 × 210 mm**（无上限）| 285 × 263 | ✅ |
| **车身高度** | **140 ~ 250 mm** | ⚠️ 待确认（底板顶面 z=98，配件须高出 ≥42mm）| 🚧 |
| **CPU** | ≤ 4 核 @ 1.5 GHz | RDK X3：4×A53@1.5G | ✅ 正好卡线 |
| **RAM** | ≤ 4 GB | RDK X3 4GB | ✅ 正好卡线 |
| **算力（BPU/GPU）** | ≤ 5 TOPS INT8 | RDK X3：5 TOPS | ✅ 正好卡线 |
| **系统** | Ubuntu ≥ 18.04 | | ✅ |
| **控制框架** | **ROS1 / ROS2** | ROS2 | ✅ |

> **★ 三条"正好卡线"**：RDK X3 4GB 的 CPU / RAM / 算力**全部贴在上限** ——
> 不能换更高的型号（如 Orin Nano 8GB），否则违规。
