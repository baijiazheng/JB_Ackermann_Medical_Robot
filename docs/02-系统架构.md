# 02 · 系统架构

## 三层分离

```
┌──────────────────────────────────────────────────────────┐
│ 【上位机】RDK X3 4GB · Ubuntu · ROS2                     │
│   感知：摄像头（200万像素 30fps）→ 二维码/标签识别       │
│   语义：理解信息指向 → (目标窗口, 目标样本)              │
│   决策：进框路径 · 语音内容                              │
│   定位：YDLIDAR T-mini Plus（直插上位机）                │
│   闭环：接收下位机反馈的转角/里程/姿态                    │
└─────────────────┬────────────────────────────────────────┘
                  │ UART（3.3V ↔ 5V 需电平处理）
                  │ 协议：定长帧 + 校验 + 心跳
┌─────────────────▼────────────────────────────────────────┐
│ 【下位机】Mega 2560 PRO MINI（插在 JB_Board V1.2 上）    │
│   接收：目标转角 δ + 目标速度 v                          │
│   执行：舵机 PWM · I²C 电机指令                          │
│   反馈：AS5600 转角 · 编码器里程 · MPU6050 姿态          │
│   播报：JQ8900-16P 语音                                  │
│   保护：看门狗 · 失联停车 · 电池低压                     │
└─────────────────┬────────────────────────────────────────┘
                  │ I²C（3.3V）+ PWM + UART
┌─────────────────▼────────────────────────────────────────┐
│ 【外设层】                                                │
│   hiwonder 四路编码电机模块 · 舵机 TBSN-K15              │
│   AS5600 · MPU6050 · JQ8900-16P + 4Ω3W 喇叭              │
│   电源：3S 11.1V → 电机直供 / 7.4V 舵机 / 5V / 3.3V      │
└──────────────────────────────────────────────────────────┘
```

## 为什么这么分

| 决策 | 理由 |
|---|---|
| **算法全在上位机** | 比赛规则要求 ROS1/ROS2；下位机算不动视觉 |
| **下位机只做「指令→执行」** | 换主控（Arduino→STM32）时上位机代码一行不改 |
| **外设接口板独立（JB_Board V1.2）** | 背板和线束永久复用，换主控只换排母那块 |
| **电机/编码器走 I²C** | hiwonder 模块自带闭环，**下位机不写 PID**，省 10 个引脚 |

## 数据流

### 上行（下位机 → 上位机）
```
转向角实际值（AS5600）· 左右轮里程（编码器）· 姿态（MPU6050）· 电池电压 · 状态字
```

### 下行（上位机 → 下位机）
```
目标转角 δ · 目标速度 v · 播报指令（哪一段音频）· 使能/急停
```

## 通信协议（待定稿）

| 项 | 建议 |
|---|---|
| 波特率 | **115200**（舵机+电机+I²C 之外余量足）|
| 帧格式 | 帧头(2B) + 长度(1B) + 命令(1B) + 数据(nB) + CRC16(2B) |
| 周期 | 上行 50Hz（20ms），下行 20Hz |
| 心跳 | 上位机 100ms 未发 → 下位机自动停车 |

## 关键路径的实时性

| 环节 | 周期 | 说明 |
|---|---|---|
| 舵机 PWM | 50Hz（20ms）| 标准舵机 |
| AS5600 采样 | 100Hz | I²C 读取 |
| 电机指令 | 50Hz | I²C 下发 |
| 上位机视觉 | 30fps（33ms）| 摄像头帧率 |
| **端到端延迟目标** | **< 100ms** | 视觉→转向生效 |
