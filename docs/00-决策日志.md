# 00 · 决策日志

> **每个设计决策都要记在这里：决定是什么、为什么、什么时候定的。**
> **更新节奏：每 3 轮对话同步一次**（和档案的 3 轮提交对齐）。
> 目的：三个月后回来看板子，能知道"为什么当初这么画"。

| **D15** | **信号线不加对地电容；电容只加在电源脚旁** | **I²C 总线电容上限 400pF**，加 100nF 直接超限 → 通信失败 | 每条信号线加电容（**会破坏 I²C**）|

| **D17** | PCB 上给 **TTS 模块留 4 个脚位**（5V/GND/TX/RX）+ 丝印 | **对冲 RDK X3 算力风险** —— 万一跑不动，焊模块就有救。成本≈0 | 不留（风险敞口）|

### 📌 D8 补充：7.4V 的三个「不能做」

| ✗ | 为什么 |
|---|---|
| 从 5V 升压到 7.4V | 5V 那路已 4.15A/5A，再抽 3.9A 去升压 → **崩** |
| 从 3S 平衡头取 2S（≈7.4V）| 只有一路放电 → **电池组失衡**，充电器报错，长期毁电池 |
| 11.1V 直供舵机 | TBSN-K15 是 **2S(7.4V)** 规格 → **烧** |

## 2026-10-05（下半场）· 电源与接口细化

| ID | 决策 | 理由 | 被否的方案 |
|---|---|---|---|
| **D18** | 反接保护用 **肖特基 MBR1045**（10A 45V，TO-220，**加散热片**）| 坏了是断路（安全）；总电流 7.7A 不算大，4.2W 加散热片能压住 | P-MOS（损耗仅 0.6W，但要多 3 个件）|
| **D19** | **I²C 上拉改到 3.3V**（原计划 5V）| **原理：I²C 是开漏输出，高电平全由外部上拉决定** → 上拉 3.3V，总线就是 3.3V，主控不会灌 5V。这样 **AS5600 可直接挂同一条总线** | 上拉 5V（**会烧 AS5600**，它没有电平转换）|
| **D20** | **删掉「给 AS5600 单独降压/转换的模块」** | D19 之后不需要了，省一个模块 + 一路线 | 单独 3.3V 模块 + 电平转换 |
| **D21** | **TTS 用 SX-TTS-E 模块，Micro USB 直插 RDK X3** | 模块自带 USB-UART + 功放 + 喇叭口，**完全脱离主板** → PCB 上连音频端子都不用留 | 板上留 TTS 座 / 走板子接线 |
| **D22** | **11.1V 和 RDK X3 的供电都不走板子** | 板上只需接已分好的 5V / 7.4V → **省掉 11.1V 端子和 5V 输出端子** | 全部从板上过 |
| **D23** | **保险丝**：主回路用**可换式**（5×20mm 玻璃管座，10A 慢断）；分路用**贴片**（慢断）| 主回路电流最大、最可能烧，要能现场换；分路电流小，贴片够用省空间 | 全部贴片（烧了要焊，调试期最不方便）/ 全部 Mini Blade（**立创封装难找**）|
| **D24** | LED 限流电阻 **220/330Ω → 1kΩ** | 现代 LED 2~5mA 够亮；原值 7.4V 那颗功耗 0.088W，0805 额定 0.125W 已到 70% | 保持原值 |
| **D25** | AMS1117 必须配 **输入 10µF + 输出 22µF**，且 **TAB 接 VOUT(3.3V)** | **无输出电容会自激振荡，3.3V 轨直接废**；TAB 是散热路径 | 不接电容（会振荡）/ TAB 悬空 |
| **D26** | 上位机 UART 分压：**上电阻 1kΩ / 下电阻 2kΩ** | `5V × 2k/(1k+2k) = 3.33V` ✓ | 反接（2k上/1k下 → 只有 1.67V，**低于 3.3V 器件的 2.0V 阈值**）|
| **D27** | **主控排母引脚以【实物】为准** | 白佳正对照实物核对过 | 照官方 pinout（可能与实物批次不同）|
| **D28** | **电机模块 和 MPU6050 模块 I²C 引脚均已做电平转换** | 白佳正验证过（所以 D19 改 3.3V 上拉后两者仍能工作）| — |

### 🔴 D23 补充：贴片保险丝选型要点

| 要点 | 说明 |
|---|---|
| **额定电流 ≥ 1.5× 正常工作电流** | 否则正常工作时误烧 |
| **必须选【慢断/延时型】** | 上电瞬间给电容充电是大电流浪涌，快断型会误动作 |
| **分断能力要够** | 11.1V 下短路电流可达几十 A |

| 支路 | 正常电流 | 保险丝额定 |
|---|---|---|
| 主回路 11.1V | 7.7A | **10A 慢断（可换式）** |
| 5V | 4.8A | 7.5A 慢断（贴片）|
| 7.4V 舵机 | 2.3A | 3.5A 慢断（贴片）|
| 3.3V | 0.05A | 0.5A（贴片）|

### 📌 D18 补充：选肖特基必须连带处理

1. ⚠️ **SS34 绝对不行**（SMA 封装 3A）→ 主回路 7.7A 要 **TO-220/D2PAK，≥10A**
2. ⚠️ **电池被吃掉 0.5V** → **低压保护阈值 +0.5V**（原 3.3V/cell=9.9V → 改测 10.4V）
3. 位置放【总开关之后、分路之前】

### 📌 D30 补充：SX-TTS-E 使用要点（白佳正提供的规格图）

| 项 | 值 / 注意 |
|---|---|
| **核心芯片** | **XFS5152CE**（科大讯飞经典 TTS，中英文）|
| **上位机接口** | **Micro USB**（板载 CH340 转串口）→ **直插 RDK X3 的 USB 口** |
| **电源** | 板载 LDO；⚠️ **确认输入电压（3.3V 还是 5V）** |
| **喇叭** | ✅ **已定：直接买模块配套的「4Ω 3W 喇叭」**<br>⚠️ **白佳正原有的喇叭是 1Ω，不能用** —— 1Ω 时功放输出 12W（`3.46²/1`），是额定 3W 的 4 倍 → **烧功放**<br>（8Ω 也能响，但音量小一半）|
| **功放** | 板载 **D 类功放**，直推喇叭，不用外接 |
| **其他接口** | 3.5mm 耳机座 / TTL 串口（A 处引针）/ RS232 / RS485（带 TVS）/ SPI·IIC |
| **⚠️ 要配置的** | **通信开关** + **波特率配置**（板上有跳线/拨码，第一次用要设对）|

## 附录：视觉实验结论（影响摄像头选型，不影响 PCB）

| 结论 | 数据 |
|---|---|
| **字高 ≈ 屏幕占画面宽 × 12%** | 98%→258px / 34%→80px / **15%→35px** |
| **门槛 25px → 占画面 ≥15% 就安全** | **最远 50cm 可行** |
| **摩尔纹** | 全部 3.6~4.0 → **不需要滤镜/全局快门** |
| **摄像头接口** | **USB 直插 RDK X3 → PCB 上不用留** |
| **曝光下限** | 全图均值 <16、亮像素 <3.4% → **完全不可用**，需手动固定曝光 |
| 已知局限 | 行距小时行数会数错（偏保守，不影响判定）|
