
## ★ 核心知识点

### 1. 阿克曼 vs 差速（运动学）

```
差速车：输入 (v, ω)  →  左轮 = v - ωW/2,  右轮 = v + ωW/2
        → 能原地转圈

阿克曼：输入 (v, δ)  →  后轮 = v,  舵机 = δ
        → 【不能原地转】，最小转弯半径 R = L / tan(δ)
```

**为了兼容 ROS 的 `cmd_vel`（上位机发的是 `v, ω`），下位机内部做反算：**

```
δ = atan( ω · L / v )

推导：ω = v/R，而 R = L/tan(δ)
     → ω = v·tan(δ)/L
     → tan(δ) = ω·L/v
```

**⚠️ `v→0` 时会除零**。物理意义：车不动不可能有角速度。
代码里的处理：`v < 2cm/s` 时视为"原地打方向"（舵机转到位，车不走）。

**★ 最小转弯半径**（决定能不能进框）：
```
R_min = L / tan(δ_max) = 200 / tan(35°) = 286 mm
```

### 2. 舵机标定表（不是线性公式）

```cpp
角度  -20   -10     0    +10   +20   +35   度
脉宽  1709  1604  1500   1391  1275  1098  µs
```

**为什么不用线性公式**：舵机内部 + 连杆几何 + 安装误差都是非线性的，
实测标定比公式准（代价是多标几个点）。

**⚠️ 已知问题**：表格是 `[-20° ~ +35°]`，**左右不对称**。
右转实际极限只有 20°，左转 35°。**待白佳正确认是机械限制还是标定未完成。**

### 3. 指令超时保护（安全必需）

```cpp
if (millis() - g_lastCmdMs > CMD_TIMEOUT_MS) {   // 500ms
    g_drive.stop();     // 上位机断了 → 必须停车
}
```

**★ 不做的后果**：上位机崩溃/线松 → 车继续执行最后指令 → **一直往前冲**。
这是机器人安全的基本要求，不能省。

## ⚠️ 装好后必须标定的三件事

| # | 标定项 | 怎么做 |
|---|---|---|
| **1** | **电机方向** | 发正速度，看哪个轮子反转 → 在 `applyMotor()` 里改符号 |
| **2** | **舵机中位** | 发 `steer=0`，看前轮是不是正的 → 不是就调 `SERVO_US_CENTER` |
| **3** | **转向极限** | 左右各打到底，确认没顶死（顶死会烧舵机）|
