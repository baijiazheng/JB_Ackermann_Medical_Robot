# 实验 01 · 拍屏 OCR 可行性验证

> **目的**：在画板/买件之前，先确认「**摄像头拍显示屏上的中文 → OCR 能读出来**」这件事成立。
> **为什么先做**：这是整个视觉方案的地基。图拍不好，模型再强也白搭。
> **成本**：10 分钟。**收益**：可能省掉一整轮返工。

---

## 一、为什么必须做这个实验

拍屏幕有三个**物理层面**的坑，和"选什么 OCR 引擎"无关：

| # | 现象 | 后果 |
|---|---|---|
| **1** | **摩尔纹** —— 摄像头像素网格与屏幕像素网格干涉 | 彩色波纹，**OCR 一个字都读不出** |
| **2** | **刷新条纹** —— 快门与屏幕刷新不同步 | 半亮半暗横条 |
| **3** | **反光 / 过曝** —— 屏幕自发光 | 一片白，字全丢 |

**还有一个数字门槛**：OCR 要求**每个汉字至少 20~32 像素高**，低于 20px 识别率断崖下跌。

---

## 二、硬件事实（2026-10-05 实测）

| 设备 | 最高分辨率 | 说明 |
|---|---|---|
| `/dev/video0` | 1280×720 | ❌ 做 OCR 不够 |
| **`/dev/video2`** | **1920×1080** | ✅ **200万像素，用这个** |

> ⚠️ **不指定设备的话默认给 640×480，别用。**

---

## 三、实验步骤

### 步骤 1 · 探测设备与分辨率

```bash
python3 probe.py
```
**看输出**：记下能给出 1920×1080 的设备号（当前是 `/dev/video2`）。

### 步骤 2 · 拍照片

```bash
# 在预估的比赛距离上，用手机/显示器显示中文，对着拍
python3 capture.py --dev 2 --size 1920x1080
```

**窗口里的按键：**

| 键 | 作用 |
|---|---|
| **空格** | 拍照，存到 `shots/` |
| **+ / -** | 增减曝光（找不过曝的档位） |
| **f** | 切换自动/手动曝光 |
| **s** | 循环切换分辨率 |
| **q** | 退出 |

**★ 拍照要点：**
1. **让屏幕在画面里占够大**（至少 1/3 宽）—— 这是每字像素数的来源
2. **多拍几张不同距离**（比如 30cm / 50cm / 80cm）
3. **多拍几张不同曝光**（看会不会过曝）
4. **顺便拍一张"轻微失焦"的** —— 有时候失焦反而能消摩尔纹

### 步骤 3 · 分析

```bash
python3 analyze.py shots/
# 或分析单张
python3 analyze.py shots/shot_01.png
```

**输出**：每张图的
- 清晰度、摩尔纹强度、曝光评价
- **检测到的文字行数 + 每行字高（像素）**
- **★ 综合判定：能 OCR / 勉强 / 不能**
- 标注图存到 `shots/annotated/`

---

## 四、判定标准

| 指标 | ✅ 能 OCR | ⚠️ 勉强 | ❌ 不能 |
|---|---|---|---|
| **每字像素高** ★关键 | **≥ 25 px** | 20~25 px | **< 20 px** |
| **摩尔纹（峰值突出度）** ★关键 | **< 8** | 8~20 | **> 20** |
| **拉普拉斯方差**（清晰度）| ≥ 150 | 80~150 | < 80 |
| **过曝像素占比** | < 3% | 3~10% | **> 10%** |

**★「字高」和「摩尔纹」是关键项，任一硬失败 → 直接判「不能 OCR」。**

### 摩尔纹指标的真实校准数据（2026-10-05 实测）

| 样本 | **峰值突出度** | 判定 |
|---|---|---|
| 实拍图（肉眼无摩尔纹）| **3.78** | ✅ |
| 合成弱摩尔纹 | 57.9 | ❌ |
| 合成中摩尔纹 | 49.7 | ❌ |
| 合成强摩尔纹 | 50.2 | ❌ |
| 合成极强摩尔纹 | 69.9 | ❌ |

> ⚠️ **踩过的坑**：最初用 `FFT 99.95分位 / 中位数` 做指标，结果是**完全反的**——
> 无摩尔纹图得 45.1，加了摩尔纹反而降到 28~30。
> 正确做法是看**峰值相对局部背景的突出度**（孤立窄峰 = 周期性干涉）。

**四项里有两项以上 ❌ → 视觉方案要重新选**（换摄像头 / 加滤镜 / 改角度 / 改算法）。

---

## 五、如果拍不好，往哪调

| 问题 | 对策（按性价比排序）|
|---|---|
| **摩尔纹严重** | ① 镜头**轻微失焦** ② 换拍摄角度 ③ 加低通滤镜 ④ 换**全局快门**摄像头 |
| **刷新条纹** | 曝光时间**设为 ≥1/50s**，或屏幕刷新周期的整数倍 |
| **过曝** | 关自动曝光 → 手动固定；或限制 AE 上限 |
| **字太小（像素不够）** | ① 摄像头**靠近** ② 换**长焦镜头** ③ 换**更高像素**摄像头 |
| **字糊** | ① 对焦（很多 USB 摄像头能手动调焦）② 增曝光 ③ 稳住不要手抖 |

## 七、这个实验的产出会用到哪

| 产出 | 影响 |
|---|---|
| **能拍清的最小距离 / 最大距离** | → 决定**摄像头安装位置** |
| **能拍清所需的分辨率** | → 决定**摄像头选型**（200万够不够） |
| **摩尔纹严重程度** | → 决定**要不要加滤镜/换全局快门** |
| **每字像素数** | → 决定 **OCR 模型选型**（小模型够不够） |
