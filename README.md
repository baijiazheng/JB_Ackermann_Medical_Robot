# JB_Ackermann_Medical_Robot

> **华北五省（市、自治区）大学生机器人大赛 · 智慧医疗服务机器人（专项赛道）**
> 一台**可无限复用的阿克曼底盘**，本轮承载「智慧医疗服务机器人」任务。

---

## 这是什么

一台能**看懂信息 → 说出来 → 自己开进框**的阿克曼底盘小车。

```
摄像头看到二维码/标签
      ↓
上位机（RDK X3 + ROS2）识别语义，判断"指向哪个体检窗口、什么样本"
      ↓
下发目标转角 δ + 目标速度 v
      ↓
下位机（Mega2560 背板）执行：舵机转向 + I²C 电机 + 语音播报
      ↓
AS5600 实测转角 + 编码器里程 + MPU6050 姿态 + 磁定位 → 闭环
      ↓
精准开进框
```

## 核心设计取向

| 取向 | 说明 |
|---|---|
| **阿克曼转向** | 比赛规则硬性要求（`底盘结构：阿克曼结构`）|
| **底盘永久复用** | 机械 + 背板 + 线束一次做对；以后换主控/换任务只动局部 |
| **三层分离** | 上位机（感知/决策）· 下位机（执行）· 外设接口板（背板，不变）|
| **全程端子** | 不用杜邦线 |
| **算法在上位机** | 下位机只做「指令 → 执行」，不写 PID |
